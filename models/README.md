## 下载
### kenlm
你可以从[kenlm](https://huggingface.co/edugp/kenlm/tree/main/wikipedia)下载对应的文件到[models/kenlm](models/kenlm)下
```{commandline}
zh.arpa.bin
zh.sp.model
zh.sp.vocab
```
### bert
你可以从[bert](https://huggingface.co/google-bert/bert-base-chinese)下载对应的文件到[models/bert](models/bert)下
```{commandline}
config.json
model.safetensors
special_tokens_map.json
tokenizer_config.json
vocab.txt
```
